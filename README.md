# CSFAIL DEMO — Experience v2

Независимый интерактивный прототип игровой витрины, вдохновлённый эстетикой CS2. **Не является официальным сайтом CSFAIL и не подключён к Steam/Valve.** Все кредиты, ставки, предметы и выигрыши виртуальные, без денежной стоимости.

## Быстрый запуск на Windows

Не нужен Node.js, npm, база данных или сборка проекта. Потребуется только **Git** и **Python 3**.

Откройте PowerShell:

~~~powershell
git clone https://github.com/Zuika1166/gfgdfgfdgd.git
cd gfgdfgfdgd
.\start-windows.bat
~~~

После запуска откройте http://localhost:8765. Чтобы завершить работу, закройте окно сервера или нажмите Ctrl+C.

Можно запустить сайт и без batch-файла:

~~~powershell
py -3 -m http.server 8765 --bind 127.0.0.1
~~~

При занятости порта используйте:

~~~powershell
py -3 -m http.server 8080 --bind 127.0.0.1
~~~

После этого откройте http://localhost:8080.

При последующих обновлениях:

~~~powershell
cd gfgdfgfdgd
git pull origin main
.\start-windows.bat
~~~

## Изменения в v2

### Визуал и эффекты
- Новый тёмный интерфейс с градиентами, подсветкой, анимацией карточек и адаптивной сеткой.
- **30 разных CS2-скинов:** изображения оружия, ножей и перчаток в списках дропа, кейсах, инвентаре и окне выигрыша.
- Анимация появления редкого приза, плавное перемещение карточек и подсветка редкости.
- Поддержка системной настройки «Уменьшить движение»: длительные анимации сокращаются.

### Кейсы
- Длинная горизонтальная лента предметов и центральный указатель.
- Итог выбирается **до** начала движения; анимация останавливается на том же предмете.
- Двойное списание во время открытия блокируется.
- После остановки скин попадает в локальный виртуальный инвентарь.

### Игровые режимы
- **Crash:** растущий множитель, Canvas-график с сеткой и свечением, анимация взрыва, досрочный вывод.
- **Wheel / Crazy Wheel:** 12 секторов, стрелка, замедляющееся вращение и результат, согласованный с выигравшим сектором.
- **Double:** движущаяся рулетка с красными, чёрными и зелёными секторами.
- **Mines:** анимированное открытие клеток, подсветка мины и вывод виртуальных кредитов.
- **Chicken Road:** анимированная дорога, шаги персонажа, индикация прогресса.
- **Defuse:** визуальная панель бомбы, цветные провода и эффекты обезвреживания.
- **Jackpot / PVP Battle:** анимированная сцена противостояния с демо-ботом.

### Прочее
- Локальный баланс, профиль, бонусы, промокод DEMO2026, история, продажа предметов и инвентарь.
- localStorage для хранения демонстрационного прогресса.
- Нет серверных платежей, интеграции Steam, реальных ставок или вывода предметов.

## Проверки

При установленном Node.js 22 или новее:

~~~powershell
node --check app.js
node --test tests/demo.test.cjs
~~~

Проверки запускаются на push в main, если GitHub Actions включены.

## Изображения скинов и авторские права

Используются публичные ссылки на обработанные изображения CS2 из каталога [steamdashboard/cs2-items-api](https://github.com/steamdashboard/cs2-items-api), который формирует игровые данные из ресурсов CS2. Нужен интернет для их загрузки; если изображение недоступно, отображается запасной значок. **CS2, Valve, Steam, имена и изображения игровых предметов принадлежат их правообладателям.** Перед коммерческим использованием необходимо проверить лицензии и разрешения. Демо-проект не передаёт реальные игровые предметы.

## Ограничения

Это **клиентский прототип**, не production-игровая платформа. RNG используется только для демонстрации UX, не криптографически защищён и не подходит для денежных игр. Нет серверной авторизации, базы данных, сетевых матчей, защиты от манипулирования локальным балансом, Steam API, реальных начислений и выплат. Графики и коэффициенты представляют **упрощённую симуляцию**, а не точный алгоритм другого сервиса. Для production потребуются backend, аудит безопасности и правовая экспертиза.

Не имитируйте официальный вход Steam или платёжную страницу. Не собирайте пароли, банковские данные или персональные сведения пользователей.
