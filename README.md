# CSFAIL — независимый интерактивный демо-аналог

Адаптивный SPA-прототип по мотивам визуального языка CS2-платформ. Он не связан с CSFAIL, Steam, Valve или другими правообладателями. Игровые названия приведены для демонстрации интерфейса.

## Запуск

Самый простой способ — открыть `index.html` в браузере. Для предсказуемой работы хеш-маршрутов можно запустить локальный сервер:

```bash
cd csfail-demo
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

Внешние JavaScript-библиотеки и backend не требуются. Шрифт Inter загружается из Google Fonts при наличии интернета, без него используется системный шрифт.

## Реализовано

- Главная страница с баннером, лентой предметов, режимами и бонусами.
- Адаптивная навигация (мобильная и десктопная).
- Каталог из 12 кейсов, фильтры, страницы кейсов, случайная выдача предметов.
- Виртуальный баланс, локальные операции, продажа предметов в инвентаре.
- Упрощённые режимы: Crash, Mines, Double, Wheel, Crazy Wheel, Defuse, Chicken Road, Jackpot и PVP Battle.
- Профиль, ежедневные награды, промокод `DEMO2026`, рейтинг, история.
- Страница виртуального пополнения и отдельные пояснения об ограничениях.
- Локальное сохранение баланса, предметов и истории в `localStorage`.

## Не реализовано (потребуются собственный backend и необходимые разрешения)

- Настоящие платежи/вывод средств, Steam OpenID, Steam API, получение/передача настоящих скинов.
- Сетевые/многопользовательские матчи, WebSocket, административная панель, базa данных.
- Криптографически проверяемый RNG: Math.random здесь подходит только для визуального прототипа, не для денежных игр.
- Полное воспроизведение оригинальной механики/контента и брендовых артов исходного сайта.

Этот проект **не должен использоваться для приёма денег**, имитации официальной авторизации Steam или выдачи себя за оригинальный сервис.

## Структура

- `index.html` — точка входа;
- `styles.css` — оформление и адаптивность;
- `app.js` — роутинг, данные, механики, localStorage.

## Проверка

Синтаксис: `node --check app.js`. Доступность UI можно проверить браузером при ширине 375 и 1440 пикселей.

## Быстрый запуск на localhost

1. Распакуйте архив проекта.
2. На Windows дважды нажмите `start-windows.bat` (понадобится Python 3).
3. На macOS/Linux выполните `./start-macos-linux.sh` из каталога проекта.
4. Откройте http://localhost:8765 в браузере.
5. Чтобы остановить сервер, нажмите Ctrl+C в терминале (или закройте окно запуска).

Важно: `localhost` — это текущий компьютер. Сервер, запущенный в удалённой среде ChatGPT, не появляется автоматически на вашем компьютере.
