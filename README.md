# NOVADROP — CS2 Playground (interactive demo)

**NOVADROP** — самостоятельная концепция премиальной CS2-платформы, исследующая удачные UX-паттерны CSFAIL и CSGORUN. Это **не официальный продукт** указанных сервисов и не копия их брендов, интерфейсов, исходников или аккаунтов. Рабочее название требует проверки прав на товарный знак перед коммерческим запуском.

[Главная](./index.html) · [План развития](./docs/ROADMAP.md) · [Чек-лист качества](./docs/QA.md)

> **Только демонстрация.** Все кредиты, кейсы, скины и результаты игр виртуальные, не могут быть проданы, обменены или выведены в Steam. Никаких реальных платежей, учётных записей, сетевых ставок или серверной защиты в текущем проекте нет.

## Быстрый запуск на Windows

Нужны Git и Python 3. Node.js и npm для запуска сайта не требуются.

Откройте **PowerShell**:

~~~powershell
git clone https://github.com/Zuika1166/gfgdfgfdgd.git
cd gfgdfgfdgd
.\start-windows.bat
~~~

Откройте **http://localhost:8765**. Скрипт автоматически попробует открыть браузер. Для остановки сервера — Ctrl+C.

Альтернатива без batch-файла:

~~~powershell
py -3 -m http.server 8765 --bind 127.0.0.1
~~~

Уже скачанную копию обновите так:

~~~powershell
cd gfgdfgfdgd
git pull origin main
.\start-windows.bat
~~~

Если порт 8765 занят:

~~~powershell
py -3 -m http.server 8080 --bind 127.0.0.1
~~~

Открывайте http://localhost:8080.

## Что сделано

### Интерфейс

- Полностью переработанная визуальная система **NOVADROP**: зелёно-бирюзовые акценты, редакторская типографика, эффектный hero и коллекционные постеры.
- Адаптивные страницы главной, арены, каталога, профиля, инвентаря, бонусов, кошелька, честности, истории, рекордов и политики данных.
- Фильтрация, поиск, сортировка и избранные кейсы.
- 30 изображений реальных скинов CS2 из публичного каталога, с запасными отображениями при недоступности изображения.
- Короткие и полные анимации, поддержка системного reduced-motion.
- Локальное сохранение состояния и миграция данных старого прототипа.

### Режимы (10)

| Режим | Возможности |
|---|---|
| Cases | Лента предметов, торможение, мгновенный пропуск, открытые шансы |
| Crash | Живой Canvas-график, растущий множитель, взрыв и досрочное завершение |
| Double | Рулетка с красными/чёрными/зелёными секторами |
| Wheel | Колесо на 12 секторов с согласованной анимацией и результатом |
| Crazy Wheel | Отдельная таблица коэффициентов и своя палитра |
| Mines | Сетка 5×5 с анимациями клеток и выбором момента вывода |
| Defuse | Панель проводов и визуальная реакция на исход |
| Chicken Road | Анимированные шаги по полосам |
| Jackpot | Режим против демонстрационного бота |
| PVP Battle | Виртуальное противостояние с ботом |
| Upgrade Lab | Выбор своего скина и цели, отображение вероятности, анимация перековки |

Игровых режимов в меню — **10**, помимо отдельного каталога кейсов. Jackpot, PVP Battle и остальные игры **не являются реальными сетевыми матчами**. Примерный вес дропа в кейсах раскрыт на каждой странице; клиентский RNG нельзя считать настоящим provably fair.

### Контроль и прозрачность

- Открытые шансы каждого предмета до открытия кейса.
- Статистическая проверка 10 000 виртуальных открытий в отдельной панели.
- Дополнительный локальный дневной лимит тестовых расходов.
- Экспорт своего прогресса в JSON и сброс локальных данных.
- Нет фиктивных онлайн-счётчиков или изображений «реальных» игроков; таблица рекордов строится только по собственным результатам.

## Тесты

Для запуска тестов нужен Node.js 22 или новее (для работы интерфейса он не требуется):

~~~powershell
node --check app.js
node --test tests/demo.test.cjs
~~~

Эти тесты проверяют клиентскую бизнес-логику, но **не** заменяют просмотр в настоящем браузере, проверку UX, адаптивности и производительности на реальных устройствах.

## Предпросмотр через GitHub Pages (без денег)

В репозитории есть **ручной** workflow .github/workflows/pages-preview.yml. Он не публикует проект автоматически.

1. Откройте репозиторий → **Settings → Pages** → в **Build and deployment** выберите **GitHub Actions**.
2. Перейдите в **Actions → Publish NOVADROP demo preview → Run workflow** на ветке main.
3. Когда job Deploy завершится, ссылка на предпросмотр появится в GitHub Pages/Actions.

Для публичного предпросмотра оставлен HTML meta robots **noindex,nofollow**, чтобы поисковики не воспринимали прототип как настоящий коммерческий оператор. Перед выпуском самостоятельного бренда и официального сайта эту настройку потребуется осознанно пересмотреть.

Демоверсия восстанавливает выбранную награду, если прервать открытие кейса обновлением страницы. Незавершённые игровые ставки в локальной симуляции при перезапуске возвращаются в демо-кошелёк. Это удобство прототипа, **не замена серверной атомарности для реальных операций**.

## Важно для коммерческого использования

Клиентский код нельзя просто переключить на настоящие деньги. **Необходимо** отдельно разработать серверное хранение ценностей, защищённую авторизацию, криптографически проверяемые результаты, мониторинг/аудит, нормативное соответствие, проверку возраста и меры ответственной игры. Valve, Steam, CS2 и все изображения/названия игровых предметов остаются интеллектуальной собственностью соответствующих правообладателей. Интерфейс не должен создавать впечатление официальной аффилиации.

Загрузка изображений требует доступа к raw.githubusercontent.com. Проект не включает в себя исполняемые сторонние скрипты или ввод Steam-пароля.
